## Summary

"The Art of Functional Programming" by Minh Quang Tran, PhD (205 pages) teaches functional programming not as a language-specific skill but as a universal way of thinking about software design. The book uses OCaml and Haskell for demonstrations while cross-referencing Java to show the contrast between functional and imperative approaches.

## Key Topics

- **Yin-Yang Duality** — The book's core learning philosophy: balance deep principles (Yin) with practical applications (Yang). Study fundamentals not for theory's sake but to solve real-world problems like JSON processing and e-commerce systems.
- **Four Pillars of FP** — Everything as an expression, abstraction through functions (Lambda calculus), immutability & purity, and dataflow programming (programs as directed graphs)
- **Universal Skills** — Parsing, type checking, compilation, and higher-order computation — techniques that apply across Swift, Kotlin, JavaScript, Python, Go, and beyond
- **Declarative Paradigm Shift** — FP underlies modern tools like React (declarative UI), Terraform (declarative infra), and Maven/Gradle (declarative builds)
- **Audience** — Designed for beginners, engineering managers, CS students, and interview preparation

## Key Insight

The book's central argument: FP is not about learning Haskell syntax — it's about adopting a mindset where programs become compositions of pure, reusable transformations on immutable data. This mindset is increasingly relevant as the industry shifts toward declarative paradigms. Learning FP fundamentals makes you adaptable to any tool or language that emerges.
