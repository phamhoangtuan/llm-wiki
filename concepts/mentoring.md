# Mentoring

The professional duty of senior programmers to pass craftsmanship to juniors. From *The Clean Coder*, which argues that technical acumen is a "meme" — it must be handed from person to person, not absorbed from textbooks.

## Why Mentoring Matters

University programs often fail to prepare graduates for industry realities:

- Academic projects have no legacy code, no production pressure, no long-lived maintenance
- Students learn theory but not professional conduct
- Only experienced practitioners can teach the *judgment* that separates coding from engineering

## The Meme Model

Craftsmanship spreads through personal transmission:

- Pair programming
- Code reviews as teaching moments
- Deliberate apprenticeship structures
- Modeling professional behavior, not just explaining it

## What Mentors Teach

Beyond technical skills:

- How to say no to unrealistic deadlines
- How to estimate honestly
- How to read and navigate legacy code
- How to communicate with stakeholders
- When to refactor and when to ship

## The Senior's Obligation

The book frames mentoring not as optional generosity but as a professional obligation. If experienced programmers don't teach, the next generation learns from trial and error — producing the same mistakes at greater cost.
