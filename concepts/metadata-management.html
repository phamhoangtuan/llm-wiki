# Metadata Management

Enabling access to definitions, lineage, and data flows. One of DAMA's eleven Knowledge Areas.

What is Metadata?

"Data about data" — information that describes the structure, meaning, origin, and usage of data assets.

Key Types

  • Business Metadata: What the data means — definitions, glossaries, business rules
  • Technical Metadata: How the data is structured — schemas, data types, formats
  • Operational Metadata: How the data is used — access logs, ETL job runs, data lineage
  • Lineage Metadata: Where data came from and how it was transformed

Role in the DAMA Framework

Metadata Management is the connective tissue of the DAMA Wheel. Every other KA depends on it — you cannot govern, model, secure, or integrate data you cannot describe.

DAMA Principle

"Managing data effectively requires Metadata."

Metadata is not optional documentation — it is the operating system of a data organization.
