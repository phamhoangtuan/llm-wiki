# Data Architecture

The blueprint for aligning data assets with organizational strategy. One of DAMA's eleven Knowledge Areas.

## Role in the DAMA Framework

Data Architecture sits alongside Data Modeling and Data Security as part of the **Plan & Design** lifecycle phase. It defines the structural and behavioral specifications for data systems — what data exists, where it lives, how it flows, and under what rules.

## Key Responsibilities

- **Data blueprints**: High-level models of enterprise data landscape
- **Integration standards**: Defining how data moves between systems
- **Technology selection**: Choosing storage, processing, and integration tools
- **Standards enforcement**: Ensuring consistency across domains

## Position in Aiken's Pyramid

Data Architecture is a Phase 1 foundational discipline — without it, organizations cannot reach advanced practices like Data Science.

## Relationship to Other KAs

- **Data Governance** provides oversight and decision rights
- **Data Modeling** discovers and communicates specific data requirements
- **Data Integration** implements the movement patterns Architecture defines
