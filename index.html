Architecture

Three-Layer Design

Raw sources feed into an LLM-managed wiki, governed by a schema that turns the agent into a disciplined maintainer.

📄

Raw Sources

Immutable source documents — articles, papers, podcasts, images. The LLM reads from them but never writes.

👤 You curate
🧠

The Wiki

Structured, interlinked HTML pages. Summaries, concept pages, comparisons, syntheses. This is the compiled knowledge.

🤖 LLM maintains
⚙️

The Schema

AGENTS.md — a constitution that defines structure, conventions, and workflows. Co-evolved between you and the LLM.

🤝 Co-evolved

Operations

Three Core Workflows

Everything you do with the wiki is one of these three operations.

📥

Ingest

  • Drop source into raw/
  • LLM reads + identifies key concepts
  • LLM discusses takeaways with you
  • Creates/updates concepts/ pages
  • Writes sources/ summary
  • Updates index.md + appends log.md
→ A single source touches 10–15 pages →
🔍

Query

  • Ask a question
  • LLM reads index.md → finds pages
  • LLM reads relevant pages → synthesizes
  • Answers with inline citations
  • Offers to file result as new syntheses/ page
→ Knowledge compounds instead of disappearing →
🧹

Lint

  • Ask for a health check
  • LLM reads every wiki page
  • Flags contradictions, orphans, stale claims
  • Reports broken links + knowledge gaps
  • You approve → LLM applies fixes
→ Wiki stays healthy as it grows →
The Loop

The Compounding Cycle

Every operation enriches the wiki. Knowledge doesn't leak — it accumulates.

Start Here

Get Started in 5 Minutes

Clone, configure your LLM agent, and ingest your first source.

1

Clone or init the repo

git clone <repo-url> llm-wiki && cd llm-wiki — or just download the scaffold and init git: git init && git add . && git commit -m "init wiki"

2

Configure your LLM agent

Point your LLM agent (Claude Code, OpenCode, Codex) at this repo. The AGENTS.md file will instruct it on how to behave as a wiki maintainer.

3

Open in Obsidian (optional)

The wiki is built with HTML pages — [[wikilinks]] in source markdown, YAML frontmatter, image attachments. Open the repo folder as an Obsidian vault for the graph view, or browse directly on GitHub Pages.

4

Ingest your first source

Drop an article into raw/articles/ and tell your agent: "ingest this". Watch it create summaries, update concept pages, and log everything.

5

Ask a question

Your first query will synthesize across the wiki. If the answer is substantial, file it as a synthesis page. The wiki just got richer.

Based on Karpathy's LLM Wiki pattern. Built for compounding knowledge.
